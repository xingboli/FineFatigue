# FineFatigue 用户使用说明

## Online Demo

在线地址：<https://xingboli.github.io/FineFatigue/>

Online Demo 适合课堂演示、公开访问、快速体验和产品原型展示。它使用与 Local Full 相同的 React/Vite 应用，但采用缩短的 walkthrough timings；Demo 流程与 Full 相近，不代表正式研究协议，也不应把 Demo 结果直接混入正式研究数据集。

Demo 可以体验：

- 概览、本地历史、报告界面和浏览器端 LocalStorage 保存。
- 认知与记忆、手指敲击、反应时、螺旋描摹、疲劳挑战和 Star Catcher。
- 在支持并授权 DeviceMotion 的手机上体验真实 IMU 校准、稳定性采集和相关分析。

Demo 不提供受试者账号、管理员后台、LAN/服务器同步、服务端 JSON 数据库、CSV 后台汇总或服务端 MiMo API；疲劳关怀使用本地规则建议。所有 Demo 记录只写入当前浏览器的 LocalStorage，不会上传服务器。清除该站点的浏览器数据会删除本机记录、当前报告、认知记录、追踪记录和设置；这不是服务端删除操作。

使用 Demo 的 IMU 功能时，应在 HTTPS 页面上点击“启用手机 IMU”，允许运动与方向权限，并轻微移动设备确认真实事件到达。没有传感器或没有授权时，页面显示“IMU 传感器不可用”，不会生成替代波形或默认分数。认知与记忆、敲击、反应、螺旋描摹和 Star Catcher 不依赖 IMU，但仍只记录实际交互。

Demo 的参数为：校准 1.5 秒、稳定性 5 秒、敲击 8 秒、疲劳挑战 10/20 秒、反应 5 个有效试次、随机等待 0.7–1.8 秒、Star Catcher 10 秒。正式研究请使用完整计时的 Local Full，并遵循 [正式实验协议](EXPERIMENT_PROTOCOL.md)。

## Local Full / Research Mode

### 1. 使用前准备

1. 使用实验室提供的 Tailscale HTTPS 地址在手机或平板浏览器打开系统。
2. 使用带有动作传感器的设备；建议先关闭省电模式并保持网络连接。
3. 首次采集前，进入左侧/底部导航的“传感器监视”，点击“启用手机 IMU”。
4. 在系统弹窗中允许“运动与方向”权限，再轻微移动设备。出现真实数据、包数量增长后即可开始。

如果页面显示“IMU 传感器不可用”，表示当前浏览器没有提供传感器接口、权限被拒绝，或尚未收到真实事件。此时不要继续把该设备作为 IMU 实验终端。

### 2. 受试者操作

#### 2.1 注册或登录

1. 点击顶部或导航栏中的账号图标，打开“用户身份与实验账号”。
2. 已有账号时选择“登录”，填写受试者编号和密码。
3. 首次参与时选择“注册”，填写唯一受试者编号和至少 8 位密码。
4. 注册提交后会显示等待审核；请联系管理员。账号审核为可用后，再使用同一编号与密码登录。

未登录也可以进行本地评测，但无法将记录同步到 LAN 服务。登录后的会话会与当前受试者编号关联。

#### 2.2 检查传感器

在“传感器监视”页确认：

- IMU 状态为“已连接”；
- 包数量持续增加；
- 加速度和角速度图显示实际随设备运动变化的曲线。

系统没有传感器模拟模式；无真实数据时页面不会展示替代波形。

#### 2.3 完成一次评测

点击“开始评测”，按页面引导依次完成：

1. 传感器调零与校验。
2. 测验 1：静止稳定性、交替敲击、反应时、螺旋描摹。
3. 重复运动负荷挑战。
4. 测验 2：再次完成上述四项。
5. 主观疲劳自评：选择评分、感受标签，可填写备注。

主观自评是实验采集的一部分，会与会话保存；它不会改变客观疲劳指数。

完成后系统自动打开报告。若已登录为受试者，应用会尝试同步；也可以打开“云端同步”面板手动点击同步。该面板名称沿用界面文案，实际同步目标是当前同源 LAN 服务。

#### 2.4 查看、导出和备份

- 在“历史对比”查看会话列表，打开某条记录回到报告。
- 报告页可导出当前会话 JSON 或使用浏览器打印。
- 同步面板可导出当前浏览器的 JSON 快照，也可以导入同格式备份。
- “设置”页可修改当前浏览器显示的受试者编号和清除本地记录。清除浏览器本地记录不等同于删除服务端已同步记录。

#### 2.5 Star Catcher

“Star Catcher”是独立的触控/鼠标标准化追踪任务。进入后点击开始，持续 25 秒跟随黄色目标的固定轨迹。完成后页面显示追踪 RMSE、在靶时间和相位滞后。该结果不会加入正式实验报告或疲劳指数，但会独立保存；登录受试者同步后，管理员可导出逐点轨迹 CSV。

#### 2.6 认知与记忆测试

“认知与记忆”与主评测并列，是独立的空间记忆配对任务，不需要 IMU，也不会改变主评测的步骤或疲劳指数。

1. 从侧边栏或移动端“更多”中打开“认知与记忆”，阅读任务说明后点击“开始测试”。
2. 页面会显示 16 张卡片。每次点击两张：相同符号会保持翻开，不同符号会短暂展示后自动翻回；等待翻回时请勿连续点击。
3. 找到全部 8 对后，页面显示本次真实的完成用时、准确率、尝试/错误次数、平均响应时间，以及记忆准确性、响应速度和任务内稳定性指标。
4. 需要保留本次逐次点击和配对明细时，点击结果页的“下载本次原始 JSON”。如浏览器提示本地存储空间不足，请先下载该文件，再释放站点存储空间或清理旧记录后重试。
5. 结果只反映这一次任务内的操作表现，不构成医学诊断。可点击“重新测试”，或点击“返回认知记录”查看本机已完成记录。
6. 概览页会显示最新一次的实际认知结果；“历史对比”中的“空间记忆测试记录”可打开以往结果。登录受试者可通过云端同步面板把记录同步到实验室 LAN 服务。

### 3. 管理员操作

#### 3.1 登录管理员端

管理员账号由部署人员在服务端 `.env` 的 `ADMIN_USERNAME` 和 `ADMIN_PASSWORD` 配置。打开账号面板，选择“登录”并填写该账号；成功后导航栏会出现“管理员后台”。

如果管理员登录提示尚未配置，请在服务端检查 `.env` 并重启 `npm start`；不要在聊天、截图或提交中公开密码。

#### 3.2 审核受试者与维护账户

在“管理员后台”中：

1. 找到状态为“待审核”的受试者。
2. 点击“批准/恢复账号”，使其成为可登录的可用账号。
3. 可对可用账号点击“停用账号”；停用后该账号不能继续同步。
4. 可填写应付金额、报酬状态、管理员备注，按“保存管理记录”保存。
5. 如需重置密码，输入至少 8 位的新密码并保存；应通过受控渠道通知受试者。

#### 3.3 导出研究数据

- “导出训练数据 CSV”：导出每个会话的派生指标、负荷信息和主观自评字段。
- “导出受试者 CSV”：导出账户状态、参与次数、自评数量及报酬管理字段。
- “导出认知测试 CSV”：导出各次已同步空间记忆任务的汇总指标，如完成用时、准确率、配对次数、响应时间和前后半程变化。
- “导出认知原始 CSV”：按长表导出每次选择与每次配对尝试，包含任务相对时间、卡片位置、配对结果和响应时间，适合后续复算指标。
- “导出原始长表 CSV”：导出完整评测的 IMU、敲击、反应和描摹等逐条记录，以及频谱数据。
- “导出追踪原始 CSV”：导出 Star Catcher 的逐点目标/指针坐标与时间戳。

导出 CSV 使用受试者编号，不含明文密码；但数据仍可能具有可识别性，应按实验方案和数据管理要求保存。

### 4. 退出

账号面板中可点击“退出”。退出会清除当前浏览器保存的登录令牌，但不会删除本地会话或服务端数据。
