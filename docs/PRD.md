# FineFatigue 产品需求文档（基于现有实现）

## 1. 项目目标

FineFatigue 用于在移动端浏览器中采集手部疲劳相关的精细运动实验数据。系统将真实惯性传感器数据、敲击、反应时和轨迹描摹结果组织为同一场实验会话，比较负荷前后表现，并为研究人员提供受试者管理和结构化数据导出。

本文件是对当前代码与实际运行方式的反向整理，不代表尚未实现的路线图。

## 2. Runtime Profiles

FineFatigue 是一个代码库中的两种运行配置，而不是两套独立产品。构建时由 `VITE_DEMO_MODE` 和 Vite mode 选择 runtime profile；共同的 React 页面、真实传感器适配器和本地存储逻辑保持一致。

### Online Demo

目标是公开访问、课堂演示、快速 walkthrough 和产品原型展示。Demo 不承担正式实验数据采集：它没有受试者账号、管理员、LAN 同步、服务端存储或服务端 MiMo。浏览器端交互仍是真实点击、Canvas、LocalStorage，以及在设备支持并授权时的真实 DeviceMotion；建议和结果只保存在当前浏览器。

### Local Full / Research Mode

目标是真实研究运行：使用完整实验计时、受试者账户、LAN 服务端 JSON 存储、同步、管理员审核和 CSV 导出。MiMo 恢复建议为可选服务，不是实验采集的必要依赖。

| Capability | Online Demo | Local Full / Research |
| --- | --- | --- |
| Assessment UI | Yes | Yes |
| Real IMU | Supported device and permission only | Supported device and permission only |
| LocalStorage | Yes | Yes |
| Full research timings | No; shortened for walkthrough | Yes |
| Authentication | No | Yes |
| LAN synchronization | No | Yes |
| Admin | No | Yes |
| CSV export | No | Yes |
| Server MiMo | No; local rules only | Optional |
| GitHub Pages | Yes | No |

当前运行参数如下；来源是 `src/config/runtime.ts`，不要将 Demo 结果当作与 Full protocol 等价的数据：

| 参数 | Demo | Full |
| --- | ---: | ---: |
| Calibration | 1.5 s | 3 s |
| Stability | 5 s | 15 s |
| Tapping | 8 s | 15 s |
| Challenge options | 10 / 20 s | 30 / 60 s |
| Reaction valid trials | 5 | 30 |
| Reaction delay | 0.7–1.8 s | 2–10 s |
| Star Catcher | 10 s | 25 s |

产品流程相近，但实验参数和后端能力不同。Full timings 才是当前 Research Mode 的正式实验实现；Demo timings 只用于课堂 walkthrough 和展示。

## 3. 用户角色

| 角色 | 进入方式 | 当前权限 |
| --- | --- | --- |
| 访客 | 未登录访问应用 | 可浏览界面、设置本地受试者编号、完成本地评测；数据只保留在当前浏览器，不能使用账号同步或管理员功能。 |
| 受试者 | 以编号和密码注册/登录，并由管理员设为可用 | 完成评测、查看本地/已同步记录、同步会话与自评、导出/导入本地 JSON 备份。 |
| 管理员（研究人员） | 使用服务器 `.env` 中的管理员账号和密码登录 | 查看受试者账号与参与次数，审核/停用账号，修改报酬记录或重置密码，导出 CSV。 |

受试者注册后默认处于 `pending` 状态；只有管理员将其设为 `active` 后，才能以受试者身份登录。

## 4. 核心功能

### 4.1 真实传感器与实验前校验

- 使用浏览器 `DeviceMotion` 读取设备加速度与旋转速率。
- 传感器页显示数据包数量、估计采样率及实时加速度/角速度波形。
- 未授权、无接口或未收到实际事件时显示不可用状态；不会以模拟数据填充图表。

### 4.2 标准实验流程

一次完整会话按固定顺序执行：

1. 传感器校验与调零。
2. 测验 1：手部稳定性（IMU）、双靶交替敲击、视觉反应、阿基米德螺旋描摹。
3. 疲劳诱发：重复运动负荷挑战。
4. 测验 2：按相同四项再次采集。
5. 主观疲劳自评：1–10 评分、感受标签和可选备注。
6. 生成并保存报告。

主观自评与该会话关联，但不参与客观疲劳指数的计算。

### 4.3 报告与分析

- 生成 0–100 的客观疲劳指数及低/轻度/中度/高等级。
- 比较负荷前后四个客观维度：手部稳定性（25%）、运动耐力（30%）、反应能力（20%）、精细运动控制（25%）。
- 展示波形、频谱、敲击间隔、反应试次和描摹轨迹等采集结果。
- 支持报告 JSON 导出及浏览器打印。

### 4.4 账户、同步与备份

- 密码使用服务端 `scrypt` 哈希存储；浏览器保存短期登录令牌。
- 受试者同步会将会话、自评、认知结果、追踪结果和设置提交到同源 LAN 服务；首次同步上传本机记录，之后按当前登录受试者的已确认记录 ID 增量上传。服务端按记录 ID 合并；出现同 ID 但不同内容时，以较新时间戳作为主记录并保留另一版本的冲突副本。
- 同步面板可导出/导入浏览器本地 JSON 快照。

### 4.5 管理与数据导出

- 管理员查看账户状态、创建/最近登录时间、实验次数和自评条数。
- 管理员可批准、恢复或停用受试者，修改报酬金额/状态/备注，以及重置受试者密码。
- 可导出会话 CSV（派生指标、负荷数据、自评字段）、完整评测原始长表 CSV、受试者 CSV（状态、参与次数、报酬记录）、认知测试汇总/原始 CSV，以及追踪任务逐点轨迹 CSV。

### 4.6 认知与记忆任务

- 提供与主评测并列的“认知与记忆”入口，不改变“测验 1 → 疲劳诱发 → 测验 2 → 主观自评”的既有实验顺序。
- 任务为 4×4 空间记忆配对：8 组本地静态符号构成 16 张卡片，每次开始时随机打乱位置。受试者逐张点击并寻找相同符号；匹配成功后保持展示，错误配对短暂展示后自动翻回，动画期间锁定输入。
- 完成后保存实际发生的逐次点击事件与配对尝试：事件同时记录墙钟时间和不受系统时钟调整影响的任务相对时间；尝试记录两次选择、是否匹配和响应时间。结果还保存总用时、正确/错误次数、准确率、每对平均移动次数、平均/中位/最快/最慢响应时间、前后半程准确率与响应时间，以及由这些任务内数据透明计算的三个 0–100 指标。
- 记忆准确性、响应速度与认知稳定性是本次任务的实验指标，仅描述交互表现；不连接大模型、不输出医学结论，也不参与疲劳指数。
- 认知记录先写入浏览器 LocalStorage；已登录受试者同步后进入其服务端账户。管理员可查看测试数量，并分别导出汇总指标 CSV 和逐选择/逐尝试的原始长表 CSV；结果页可下载当前记录的原始 JSON。

### 4.7 其他界面功能

- 简体中文/英文切换。
- Star Catcher：独立的鼠标/触控标准化追踪任务。固定 25 秒李萨如目标路径，记录原始指针轨迹、RMSE、在靶时间和相位滞后；不写入正式实验会话或疲劳指数，但会独立保存、同步和导出。
- 疲劳关怀卡片：尝试调用服务端 MiMo 建议接口；不可用时使用本地规则建议。

## 5. 主要业务流程

```text
Online Demo（GitHub Pages）
  ├─ 访客：设置本地编号 → 浏览器本地评测/认知/追踪 → 本地记录
  └─ 不连接账号、LAN 服务、管理员或服务端 AI

Local Full（Tailscale HTTPS）
  ├─ 访客：设置本地编号 → 授权 IMU → 完成评测 → 本地报告
  │         └─ 或：打开认知与记忆 → 完成空间配对 → 本地认知记录
  ├─ 受试者：注册 → 管理员审核 → 登录 → 完成评测或认知任务 → LAN 同步
  └─ 管理员：登录 → 审核账号/记录报酬 → 导出会话、原始、用户、认知或追踪 CSV
```

完整评测结束后的报告和主观自评，以及单独完成的认知任务结果，都会先写入浏览器 LocalStorage。若当前为已登录受试者，应用会安排同步请求；同步失败时数据继续保留在本地并显示离线状态，随后最多自动指数退避重试 3 次，浏览器恢复网络时也会再次尝试。

## 6. 当前功能边界

- 仅采集浏览器能够提供的 `DeviceMotion` 数据；不接入蓝牙、串口或外置 IMU。
- 不提供真实数据库、对象存储、团队权限分级、邮件通知、支付或报酬发放。
- 服务端数据文件是单机 JSON 文件，适合实验室局域网的小规模单实例运行，不是多实例或高并发部署方案。
- 不提供医学诊断、风险判定或临床建议；疲劳指数是当前规则公式计算的研究指标。
- 不提供受试者注册后的自动审批；管理员必须手动操作。
- 不提供服务端删除同步会话的接口；界面删除主要影响当前浏览器缓存。
- 认知模块当前只有空间记忆配对这一种任务；不包含词语回忆、题库、常模或临床阈值，不能据此诊断认知疾病。
